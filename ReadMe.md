
# User Cards Application

A simple and responsive web application that fetches user information from the JSONPlaceholder API using JavaScript Fetch API and displays the data in a responsive card layout.

## Features

- Fetch user data from REST API using JavaScript Fetch API.
- Display user information in responsive cards.
- Dynamically render API data using JavaScript.
- Responsive UI for desktop, tablet, and mobile devices.
- Clean and simple card-based interface.

## API

- **API URL:** https://jsonplaceholder.typicode.com/users
- **Method:** GET
- **Data:** User details including name, email, phone, city, and company.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- JSON
